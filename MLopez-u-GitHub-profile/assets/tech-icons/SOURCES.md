Missing Skill Icons are shown with official brand marks in matching rounded-square tiles. The tile background colors are decorative; the marks remain their respective owners’ property.

Icon assets: Devicon (ASP.NET Core, SQL Server, Oracle, VBA), Simple Icons (UiPath, Appian), Microsoft Power Platform (Power Automate), and SS&C Blue Prism (Blue Prism). The main rounded-square set is Skill Icons: https://github.com/tandpfun/skill-icons.
